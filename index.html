Projetos

MLP do zero em numpy

Esse projeto se trata da implementação de uma rede neural do zero utilizando Python. Aqui, implemento camadas lineares e não lineares, juntamente com o algoritmo de backpropagation, pronto para o treinamento de problemas de classificação e regressão.

Foi um projeto interessantíssimo para entender a fundo como redes neurais funcionam por baixo dos panos em bibliotecas como PyTorch e TensorFlow. Implementei customização no número e dimensões das camadas, além do uso de diferentes funções de ativação e de perda e algoritmos de otimização.

Nesse sentido, pode-se dizer que é o "Hello World" do mundo da inteligência artificial.

Projeto WGAN

Esse projeto se trata da reprodução de um artigo que propõe um sistema de detecção de intrusão com o uso de WGAN e técnicas de Self-Attention e TCN para classificar pacotes de rede.

O objetivo foi construir um sistema que aprende os padrões de uma rede para detectar ataques. O sistema é validado, então, com vários exemplos de ataques ddos.
